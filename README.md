# Craftybot - Minecraft Server Status Checker Website
This is a website, made in Python using Streamlit, through which people could check their gameserver status. They could check number of players, uptime, and other server parameters. Alongside, they can also do a ping test to get a quite accurate ping which a player would get when they join from the same network as the test.

I have also put a latency checker. This means people could see the average latency of their server directly from their browser, without needing to open the game!

I would be using streamlit, as its a really cool library to make websites through python.

# Setting it up
To set up Craftybot, you have to:

1. Clone the repo onto a server/vps.
```git clone https://github.com/brahmtej2009/craftybot``` 
2. Download dependencies
```pip install -r requirements.txt```                  
3. Run app
```python3 -m streamlit run app.py```
